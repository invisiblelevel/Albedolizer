1. Введение

Albedolizer — standalone-инструмент для Windows для 3D-художников, геймдизайнеров и всех, кто работает с PBR-текстурами. Проверяет Albedo-карты на соответствие стандартам, автоматически корректирует цвет через AI, генерирует полный набор PBR-карт, упаковывает их под целевой движок и позволяет посмотреть результат во встроенном 3D-вьюере.

Два режима UI

  • Simple — воркфлоу в один клик (Open → AI correct → Save). Продвинутые инструменты скрыты.
  • Advanced — полный контроль. Открывает статистику, методы коррекции, удаление мыла, насыщенность, тайлинг, seamless и прочее.

Переключение режимов — кнопкой ⚙ Simple / ⚙ Advanced в хедере.

2. Хедер и навигация

Хедер содержит название приложения, текущую версию, переключатель режима UI, темы, языка и кнопку Info.

NavigationRail слева даёт доступ ко всем вкладкам:

  • Single — проверка и коррекция одной текстуры
  • Batch — обработка целой папки
  • PBR — генерация PBR-карт
  • Engine — упаковка карт под Unity / Unreal / Godot
  • Compress — уменьшение размера файла
  • Realism — процедурный фильтр фотореализма

3. Вкладка Single

Simple mode

В Simple-режиме одна кнопка делает всё: 🚀 Auto-correct. Открывает файл, запускает AI-коррекцию цвета, поднимает насыщенность и показывает результат.

Advanced mode

В Advanced-режиме доступен полный контроль:

  1. Выбери Texture type справа (или нажми 🤖 Auto-detect material)
  2. 📂 Open — загрузить Albedo-текстуру
  3. 🔍 Check — посмотреть статистику и heatmap
  4. Если FAIL → ✨ Auto-Correct
  5. 💾 Save результат
💡 Используй ↺ Reset, чтобы в любой момент сравнить скорректированное изображение с оригиналом.

4. Правая панель Single

Правая панель вкладки Single содержит всё для настройки коррекции:

  • Auto-detect material — CLIP-классификатор подбирает лучший пресет из 47 вариантов
  • Texture type — категории (🔥 Metal, 🌿 Nature, 🪨 Mineral, 🧪 Synthetic, 🧵 Fabric, 💧 Special, 🐾 Fauna) и пресеты внутри каждой
  • Correction method — Autolevels / LUTwithBGrid / Math
  • Tiling 3×3 — поиск швов на тайлящихся текстурах
  • Seamless — сделать текстуру бесшовной через радиальную маску + scatter
  • Remove soap — адаптивный unsharp mask для размытых участков
  • Saturation — исправить блёклые цвета после AI-коррекции
  • Statistics — min / max / avg / медиана / перцентили

5. Вкладка PBR

Генерация полного набора PBR-карт из одной Albedo-текстуры.

  1. 📂 Load Albedo — выбрать текстуру
  2. Выбрать пресет справа (слайдеры подстроятся автоматически)
  3. Подкрутить слайдеры при необходимости (Normal strength, Smoothing, Threshold, High-pass, Height blur, AO radius, AO intensity, Rough base, Rough variation)
  4. 🎨 Generate → 7 карт
  5. Переключаться между картами кнопками сверху: Albedo / Height / Normal / AO / Rough / Metal / Edge / ORM
  6. 👁 3D Preview — открыть OpenGL-вьюер
  7. 💾 Save all — создаст папку <имя>_pbr/ рядом с исходником
💡 Height и Normal сохраняются в 16-битный PNG при выборе соответствующей опции — полная точность для про-пайплайнов.

6. Engine Export

Упаковка PBR-карт под конкретный движок в один клик.

Источник

  • ⚙️ From current PBR — использовать карты, только что сгенерированные во вкладке PBR
  • 📂 Load from folder — выбрать папку с готовыми *_albedo.png, *_normal.png, *_ao.png и т.д.

Поддерживаемые движки

ДвижокРаскладка
Unity HDRPR = Metallic, G = AO, B = Detail Mask, A = Smoothness (1 − Roughness)
Unity URPR = Metallic, G = 0, B = 0, A = Smoothness (1 − Roughness)
UnrealR = AO, G = Roughness, B = Metallic
GodotR = AO, G = Roughness, B = Metallic

Дополнительные опции

  • Normal map format — OpenGL (Y+) или DirectX (Y−) с инверсией зелёного канала
  • Detail Mask (только HDRP) — white (1.0) / edge map / своя, загруженная с диска
  • PNG bit depth — 8-bit или 16-bit
  • Channel preview — R / G / B / A / RGB / RGBA

Нажми ⚙️ Pack, чтобы сгенерировать упакованную карту, затем 💾 Save all — запишет <имя>_<движок>_<gl|dx>/ рядом с исходником.

7. Фильтр Realism

Добавляет процедурный эффект фотореализма на Albedo-текстуры — зерно, микродетали, цветовые вариации и лёгкую виньетку.

  1. 📂 Open — загрузить текстуру
  2. Настроить три слайдера:
    • Grain — слои мелкого и крупного шума
    • Detail — адаптивный high-pass overlay для микродеталей
    • Variation — крупномасштабные цветовые/яркостные пятна + виньетка
  3. 🎞 Apply — увидеть результат в превью
  4. 💾 Save результат
💡 Для 8K-текстур фильтр может занять несколько секунд — прогресс-бар покажет статус.

8. Пакетная обработка

Обработать целую папку текстур сразу — AI-коррекцией или сжатием.

  1. 📁 Select folder или 📄 Select files
  2. Выбрать метод коррекции (Autolevels / LUTwithBGrid / Math) справа
  3. Выставить число потоков (1–8 параллельных задач)
  4. Опционально подкрутить силу Remove soap
  5. ▶ Run processing

Результаты сохраняются в папку _corrected рядом с исходниками.

9. Сжатие

Уменьшение размера файла Albedo-текстур без потери визуального качества.

  • Одиночное сжатие — 📂 Open файл, нажать 🗜 Compress, затем 💾 Save
  • Пакетное сжатие — 📁 Select folder или 📄 Select files, затем ▶ Compress folder

Выбрать 8-bit или 16-bit PNG на правой панели.

Результаты идут в папку _compressed рядом с исходниками.

10. Панель лога

Внизу окна — единая общая панель лога. В свёрнутом виде показывает только последнюю строку. Клик по хедеру разворачивает полную историю.

  • Клик по хедеру лога — свернуть / развернуть
  • Клик по 🗑 — очистить лог

11. 3D-вьюер

Просмотр PBR-результата на объекте в реальном времени, с HDRI-освещением и размытыми отражениями.

Управление

  • Левая кнопка мыши — вращать объект
  • Колесо мыши — приближение / отдаление
  • Shape — Sphere / Cylinder / Cube / Plane — переключение формы объекта
  • Exposure — слайдер яркости (0.5 – 2.0)
  • Tiling — кнопки X / Y меняют масштаб текстуры от 1×1 до 16×16
  • Reset 4x3 — вернуть тайлинг по умолчанию
💡 Вьюер открывается отдельным окном (viewer.exe) при нажатии 👁 3D Preview во вкладке PBR.

12. Диалог Info

Нажми ℹ Info в хедере, чтобы открыть диалог информации. Внутри:

  • Help — краткая справка обычным текстом
  • About — версия, дата сборки, автор
  • Support — донат-кошельки (BTC, USDT, GRAM)
  • Manual — этот HTML-файл, открывается в браузере

1. Introduction

Albedolizer is a standalone Windows tool for 3D artists, game designers, and anyone working with PBR textures. It checks Albedo maps against standards, automatically corrects color via AI, generates a full set of PBR maps, packs them for your target engine, and lets you preview the result in a built-in 3D viewer.

Two UI modes

  • Simple — one-click workflow (Open → AI correct → Save). Advanced tools are hidden.
  • Advanced — full control. Unlocks statistics, correction methods, soap removal, saturation, tiling, seamless, and more.

Switch modes via the ⚙ Simple / ⚙ Advanced button in the header.

2. Header & Navigation

The header contains the app title, current version, UI mode toggle, theme switcher, language switcher, and the Info button.

The NavigationRail on the left gives access to all tabs:

  • Single — check & correct one texture
  • Batch — process a whole folder
  • PBR — generate PBR maps
  • Engine — pack maps for Unity / Unreal / Godot
  • Compress — reduce file size
  • Realism — apply procedural photorealism filter

3. Single tab

Simple mode

In Simple mode, one button does everything: 🚀 Process texture. It opens a file, runs AI color correction, boosts saturation, and shows the result.

Advanced mode

In Advanced mode you get full control:

  1. Pick a Texture type on the right (or click 🤖 Auto-detect material)
  2. 📂 Open — load an Albedo texture
  3. 🔍 Check — see stats and heatmap
  4. If FAIL → ✨ Auto-Correct
  5. 💾 Save the result
💡 Use ↺ Reset to compare the corrected image with the original at any time.

4. Single right panel

The right panel of the Single tab contains everything you need to configure the correction:

  • Auto-detect material — CLIP-based classifier picks the best preset from 47 options
  • Texture type — categories (🔥 Metal, 🌿 Nature, 🪨 Mineral, 🧪 Synthetic, 🧵 Fabric, 💧 Special, 🐾 Fauna) and presets inside each
  • Correction method — Autolevels / LUTwithBGrid / Math
  • Tiling 3×3 — spot seams on tileable textures
  • Seamless — make a texture tileable with radial mask + scatter
  • Remove soap — adaptive unsharp mask for blurry patches
  • Saturation — fix washed-out colors after AI correction
  • Statistics — min / max / avg / median / percentiles

5. PBR tab

Generate a full set of PBR maps from a single Albedo texture.

  1. 📂 Load Albedo — pick a texture
  2. Pick a preset on the right (sliders auto-tune)
  3. Adjust sliders if needed (Normal strength, Smoothing, Threshold, High-pass, Height blur, AO radius, AO intensity, Rough base, Rough variation)
  4. 🎨 Generate → 7 maps
  5. Switch between maps with the buttons on top: Albedo / Height / Normal / AO / Rough / Metal / Edge / ORM
  6. 👁 3D Preview — open the OpenGL viewer
  7. 💾 Save all — creates a <name>_pbr/ folder next to the source
💡 Height and Normal maps are saved in 16-bit PNG when selected — full precision for pro pipelines.

6. Engine Export

Pack your PBR maps for a specific engine in one click.

Source

  • ⚙️ From current PBR — use the maps you just generated in the PBR tab
  • 📂 Load from folder — pick a folder with existing *_albedo.png, *_normal.png, *_ao.png, etc.

Supported engines

EngineLayout
Unity HDRPR = Metallic, G = AO, B = Detail Mask, A = Smoothness (1 − Roughness)
Unity URPR = Metallic, G = 0, B = 0, A = Smoothness (1 − Roughness)
UnrealR = AO, G = Roughness, B = Metallic
GodotR = AO, G = Roughness, B = Metallic

Additional options

  • Normal map format — OpenGL (Y+) or DirectX (Y−) with green channel flipped
  • Detail Mask (HDRP only) — white (1.0) / edge map / custom loaded from disk
  • PNG bit depth — 8-bit or 16-bit
  • Channel preview — R / G / B / A / RGB / RGBA

Click ⚙️ Pack to generate the packed map, then 💾 Save all to write <name>_<engine>_<gl|dx>/ next to the source.

7. Realism filter

Add a procedural photorealism effect to Albedo textures — grain, micro-detail, color variation, and a subtle vignette.

  1. 📂 Open — load a texture
  2. Tune three sliders:
    • Grain — fine and coarse noise layers
    • Detail — adaptive high-pass overlay for micro-detail
    • Variation — large-scale color/brightness patches + vignette
  3. 🎞 Apply — see the result in the preview
  4. 💾 Save the result
💡 For 8K textures the filter may take a few seconds — a progress bar shows the status.

8. Batch processing

Process a whole folder of textures at once with AI correction or compression.

  1. 📁 Select folder or 📄 Select files
  2. Choose correction method (Autolevels / LUTwithBGrid / Math) on the right
  3. Set threads count (1–8 parallel tasks)
  4. Optionally tune Remove soap strength
  5. ▶ Run processing

Results are saved to a _corrected folder next to the sources.

9. Compression

Reduce file size of Albedo textures without losing visual quality.

  • Single compression — 📂 Open a file, click 🗜 Compress, then 💾 Save
  • Batch compression — 📁 Select folder or 📄 Select files, then ▶ Compress folder

Choose 8-bit or 16-bit PNG on the right panel.

Results go to a _compressed folder next to the sources.

10. Log panel

At the bottom of the window there is a single shared log panel. When collapsed, it shows only the last line. Click the header to expand it and see the full history.

  • Click the log header to toggle collapsed / expanded
  • Click 🗑 to clear the log

11. 3D Viewer

Preview your PBR result on a shape in real time, with HDRI lighting and blurred reflections.

Controls

  • Left mouse button — rotate the object
  • Mouse wheel — zoom in / out
  • Shape — Sphere / Cylinder / Cube / Plane — switch the object shape
  • Exposure — brightness slider (0.5 – 2.0)
  • Tiling — click X / Y buttons to change texture scale from 1×1 to 16×16
  • Reset 4x3 — restore the default tiling
💡 The viewer opens as a separate window (viewer.exe) when you click 👁 3D Preview in the PBR tab.

12. Info dialog

Click ℹ Info in the header to open the info dialog. It contains:

  • Help — quick reference in plain text
  • About — version, build date, author
  • Support — donation wallets (BTC, USDT, GRAM)
  • Manual — this HTML file, opens in your browser
